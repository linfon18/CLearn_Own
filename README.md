## 课程方向 ✨

- 🧑‍💻 《程序设计基础》：记录 C 语言基础语法、课堂练习和课后实践
- 🐧 《Linux操作系统及应用》：记录 Linux 基础命令、系统使用和实验过程
- 📝 学习笔记与代码练习：保存每一阶段的学习成果
